# Data availability

This repository contains **no raw EMG, pose, HDF5, participant-level records, model checkpoints, or derived dataset payloads**. The study used official third-party research data, including the emg2pose paired sensing data and Ninapro DB9 for the independently trained posture consumer. Readers must obtain each source from its official distributor and comply with its current terms. This public summary does not grant rights to redistribute either dataset.

The final result tables here are aggregate derivatives. The detailed frozen scientific archive, participant lineage, receipts, and executable model artifacts are retained outside this public repository. Requests for controlled scientific verification can be discussed with the project owner, subject to data, privacy, and intellectual-property review. The absence of those materials means this repository alone does not reproduce inference end to end.

Data source descriptions and access terms can change; consult the official [emg2pose project](https://github.com/facebookresearch/emg2pose) and [Ninapro project](https://ninapro.hevs.ch/) when acquiring source materials.
